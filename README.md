# Sonita Birthday Surprise ❤️

A sweet, mobile-first birthday surprise website featuring a personal birthday song.

## GitHub Pages
1. Create a new GitHub repository.
2. Upload `index.html`, `style.css`, `script.js`, and the `video` folder.
3. Open the repository's **Settings → Pages**.
4. Choose **Deploy from a branch**, select `main` and `/ (root)`.
5. Save and wait for GitHub Pages to publish.

Keep the `video` folder in the same location as `index.html` so the video path works.
